# Cybersecurity Projects

A collection of hands-on cybersecurity projects focused on incident response, network forensics, traffic analysis, and security investigations. This repository showcases practical experience analyzing security events, identifying indicators of compromise, and documenting findings in a clear technical format.

## Projects

### Incident Response Casework
Investigated a security scenario using Splunk searches to identify suspicious activity and indicators. Pivoted across logs to attribute actions to hosts and users, then developed an incident timeline to document the progression of events. Delivered a structured case report including findings, indicators of compromise (IOCs), and remediation recommendations.

**Key skills demonstrated:**
- Log analysis with Splunk
- Threat hunting and pivoting
- IOC identification
- Timeline development
- Incident documentation and reporting

### Phishing PCAP Investigation
Analyzed packet captures to extract email-related traffic and identify phishing indicators. Traced message flow, suspicious domains, IP addresses, and artifacts from network evidence. Summarized findings in a short forensic report covering headers, endpoints, and payload clues relevant to the investigation.

**Key skills demonstrated:**
- Packet analysis
- Email traffic investigation
- Network forensics
- Phishing detection
- Evidence-based reporting
